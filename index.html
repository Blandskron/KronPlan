Ingeniería y UX

Simple por diseño, estricto en garantías

Sin frameworks SPA en el navegador ni estados duplicados: cada transición crítica se decide en Django y se difunde por WebSocket.

Privacidad de votos en servidor

Antes del reveal, ningún payload WebSocket ni respuesta HTTP expone votos ajenos; solo el estado de interacción (has_voted).

Tiempo real con Channels + Redis

Sincronización instantánea de asientos, cartas, cola de historias, reconexión multi-pestaña y cierre de sala vía ASGI/Daphne.

Frontend nativo sin build bloat

Django Templates, CSS con capas --kp-* y Vanilla JavaScript con Content-Security-Policy estricta basada en nonce.

Identidad y gamificación opcional

Mascotas SVG originales, 7 colores de asiento, lanzamientos cosméticos con rate-limit en servidor y modo recreo desactivables.

WCAG 2.2 AA & Carcasa Móvil

Contrastes verificados sobre DOM real, atajos de teclado (0–8, ?, flechas), prefers-reduced-motion y baraja apilada al pulgar.

Quality Gates automatizados

Ruff, Pytest + Channels, Playwright E2E, axe-core, Lighthouse, check --deploy y arranque verificado en contenedor Docker.

Autoalojamiento Open Source

Levanta tu instancia en minutos

Ejecuta KronPlan en local para desarrollo o despliégalo en producción con Docker Compose, PostgreSQL y Redis.

Producción con Docker Compose

Incluye PostgreSQL, Redis para Django Channels, Daphne ASGI y endurecimiento de seguridad con DJANGO_DEBUG=False.

git clone https://github.com/Blandskron/KronPlan.git
cd KronPlan
cp .env.example .env
docker compose up --build -d

Desarrollo local (Python 3.12+)

Cero compiladores Node o bundlers: instala dependencias Python, aplica migraciones y arranca el servidor en vivo.

python -m venv .venv
. .venv/bin/activate
pip install -r requirements-dev.txt
python manage.py migrate && python manage.py runserver
